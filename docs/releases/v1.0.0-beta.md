# Cross Road iPhone/PWA — v1.0.0 Beta

## [▶ PLAY NOW](https://qqclutchyqq.github.io/cross-road-ios/)

On iPhone/iPad: open in **Safari → Share → Add to Home Screen**. Launch Cross Road, then choose KHUX or Dark Road. No IPA download or sideloading is needed.

This is a **beta community preservation release**, approved by the maintainer for public testing after physical-iPhone testing. Compatibility and bug reports are welcome on [Traverse Town Discord](https://discord.gg/jHWEkRdjJb).

## Included

- KHUX + Dark Road playable through iPhone Safari/Home Screen PWA.
- Automatic remote Content loading and caching; no manual 2+ GB folder setup.
- Mobile touch controls and working game audio.
- Locally stored progress, Save Game Editor, and backup/import tools.
- Portrait/landscape support and the in-game controls menu.
- Copy/Export Diagnostics and device/audio lifecycle information.

## Before playing

Keep an internet connection for uncached game data. Progress stays on your device/browser and is not uploaded to GitHub or Cloudflare. Export backups periodically; clearing website data or loss of browser storage can remove local progress.

Earlier iPhone reports of native KHUX popup tap-through, stuck dismissal controls and stacked dimming have not been separately confirmed resolved for this beta.

Audio may need the first normal tap after returning from another app. Unusual device-specific iOS/WebKit behavior remains a beta testing area.

For reports, include device/OS, Safari or Home Screen mode, KHUX or Dark Road, reproduction steps, and reviewed diagnostics. Do not post save files or private information publicly.

## Preservation and release baseline

This release preserves the existing v14 runtime from [`9e06b47b578c245a00b222977f0edc61358266f4`](https://github.com/qqCLUTCHYqq/cross-road-ios/commit/9e06b47b578c245a00b222977f0edc61358266f4). The release presentation adds documentation and community/support files only; it does not alter gameplay, audio, Content, saves or service-worker caching.

The original Cross Road author/contributor credits and third-party acknowledgements remain intact. No new license is applied to the original game/runtime material. See [credits and provenance](https://github.com/qqCLUTCHYqq/cross-road-ios#credits--provenance) and [technical history](https://github.com/qqCLUTCHYqq/cross-road-ios/blob/main/TECHNICAL.md).

Use the Play link above. GitHub's automatically generated source archives are repository snapshots, not an iPhone installer or a bundled Content download.
