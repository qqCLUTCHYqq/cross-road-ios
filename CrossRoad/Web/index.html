Project χ: Cross Road

Kingdom Hearts Union χ and Dark Road preservation runtime for Safari and iPhone Home Screen.

Launch gameLaunch with diagnostics

Install on iPhone

Open this page in Safari, tap Share, choose Add to Home Screen, then launch Cross Road from the new icon. Game Content loads automatically from Cloudflare R2. No folder download or selection is needed.

The game runtime is about 28 MB. Content streams as needed and is cached on your device. An internet connection is required for uncached game data.
